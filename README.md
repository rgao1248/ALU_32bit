My first attempt at a 32-bit ALU in Verilog. 

Uses a 32-bit ripple-carry adder module for the addition, subtraction, and signed/unsigned comparison functions. Also has two additional separate modules for left-shifting and one for both logical and arithmetic right-shifting.
